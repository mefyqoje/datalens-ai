# DataLens AI

DataLens AI — веб-приложение на Streamlit для первичного анализа CSV-данных,
построения графиков и сравнения базовых моделей машинного обучения. Приложение
помогает быстрее перейти от таблицы к первым выводам без написания
аналитического кода.

## Возможности

- Загрузка CSV-файла и просмотр его содержимого.
- Обзор набора данных: число строк и столбцов, пропуски и дубликаты.
- Описательная статистика, типы столбцов и число уникальных значений.
- Интерактивные гистограммы, графики частот, диаграммы рассеяния и тепловая
  карта корреляций числовых признаков.
- Обучение моделей классификации или регрессии с выбором целевого столбца.
- Сравнение линейной модели, дерева решений и случайного леса с базовым
  алгоритмом на отложенной выборке.
- Просмотр и скачивание таблицы в формате CSV.

Для классификации показываются Accuracy и взвешенная F1-мера. Для регрессии —
MAE, RMSE и R². Эти оценки получены на одной отложенной выборке и сами по себе
не гарантируют качество модели на новых данных.

## Требования

- Windows и PowerShell.
- Python 3.11 или новее.
- Git — если проект клонируется из Git-репозитория.

Все зависимости устанавливаются в локальное виртуальное окружение `.venv`;
глобальная установка пакетов не требуется.

## Установка и запуск в Windows

Откройте PowerShell в папке проекта и выполните команды по порядку.

1. Создайте виртуальное окружение на Python 3.11:

   ```powershell
   py -3.11 -m venv .venv
   ```

2. Активируйте его в текущем окне PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Установите приложение и инструменты для разработки в это окружение:

   ```powershell
   python -m pip install -e ".[dev]"
   ```

4. Запустите веб-приложение:

   ```powershell
   streamlit run src\datalens_ai\app.py
   ```

5. Откройте указанный Streamlit адрес, обычно `http://localhost:8501`.

Если PowerShell запрещает запуск скрипта активации, не меняйте системную
политику выполнения: запускайте приложение напрямую из окружения:

```powershell
.\.venv\Scripts\python.exe -m streamlit run src\datalens_ai\app.py
```

## Запуск тестов

При активированном окружении выполните:

```powershell
python -m pytest
```

## Ограничения текущей версии

- Приложение рассчитано на первоначальный анализ табличных CSV-данных, а не на
  полноценную автоматическую настройку моделей.
- Результаты зависят от состава и качества данных, выбранного целевого
  столбца и разделения на обучающую и проверочную выборки.
- Перед выводами о качестве модели проверьте, нет ли среди признаков данных,
  напрямую раскрывающих целевой столбец. Для временных данных случайное
  разделение может быть неподходящим.
- Генерация отдельного отчёта пока не реализована.
